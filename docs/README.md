# Documentation Guide

This folder contains supporting manuscript and figure documentation.

| File | Purpose |
|---|---|
| `Research_report.tex` | Current manuscript text snapshot used for figure/caption context. |
| `SI_Appendix.tex` | Current supplementary information snapshot. |
| `figure9.md`, `figure12.md`, `figure13.md` | Figure-specific notes. |
| `figure9_stat_table.tex` | LaTeX-formatted statistical table for Fig. 1-related results. |
| `drosophila_branson_epoch_check.md` | Notes on the Drosophila calcium-imaging dataset and epoch/stimulus interpretation. |
| `functional_class_literature_basis.md` | Rationale and literature basis for cross-species functional-group assignments. |

These files are included for transparency and editing context; figure scripts do not generally depend on them.
