# Statistics tables

This folder contains a compact set of CSV tables used to report or verify the final figure results. It mirrors the key tables from `data/final_summary_tables/` and selected supplementary outputs, without copying every intermediate analysis table.

Use these files when checking manuscript values, panel-level statistics, model summaries, or figure-specific plotted values. The larger `data/final_summary_tables/` directory contains additional intermediate and audit tables used by the plotting scripts.

## Contents

- `figure9_*`: zebrafish FC/TE and structural-connectivity statistics.
- `figure12_*`: division-level structural-connectivity statistics.
- `figure_sc_fc_final_overview_*`: SC--FC correlation, prediction, and model-weight summaries.
- `figure13_*`: layer-model and perturbation-simulation summaries.
- `figure14_15_*`-related outputs are embedded in the cross-species figure scripts and summary files.
- `figure7_*`: cross-species functional-group and stimulus-associated FCV summaries.
- `figure_supply_14_*`: stimulus-condition FCV heatmap values.
